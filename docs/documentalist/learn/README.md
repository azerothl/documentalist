# Démarrer en local

Avec Node.js 22, exécuter les commandes ci-dessous depuis la racine. Ouvrir ensuite http://localhost:3000/setup et utiliser le code écrit dans data/setup-token pour créer le premier compte administrateur.

```sh
npm install
npm run dev
```
