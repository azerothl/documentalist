# Utiliser la skill avec un agent

La skill documentalist-docs explique comment préparer les dossiers, la navigation et un profil d’import GitHub. Depuis un checkout qui contient la skill, demandez à l’agent d’appliquer documentalist-docs au projet cible. Pour la transmettre à un autre agent, fournissez son fichier SKILL.md en entier.

Le fichier se trouve dans .agents/skills/documentalist-docs/ à la racine du dépôt Documentalist.
