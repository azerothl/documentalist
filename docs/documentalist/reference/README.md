# Documentalist

Documentalist organise des documents en espaces et permet de publier des portails par langue et version. L’import GitHub alimente Reference, Learn et Blog à partir de dossiers configurés dans l’espace.

## Préparer un import GitHub

Préparer des racines distinctes contenant du Markdown. Le dossier docs alimente Reference. Learn et Blog sont facultatifs. SUMMARY.md fixe l’ordre par liens dans une racine, tandis que les dates ordonnent les notes de Blog. Configurer le dépôt et la branche dans l’interface avant de lancer l’import.
